# CUSTOMER CHURN PREDICTION


# PROJECT OVERVIEW

Customer Churn Prediction is a Machine Learning project that identifies customers who are likely to stop using a company's services.

The main goal of this project is to analyze customer data, identify churn patterns, and predict whether a customer will leave the company or continue using its services.


# OBJECTIVES

- Analyze customer information and behavior.
- Identify important factors influencing customer churn.
- Perform Exploratory Data Analysis (EDA).
- Visualize customer churn patterns.
- Build a Machine Learning classification model.
- Predict whether a customer will churn or not.

  
# DATASET INFORMATION

- Dataset: Telco Customer Churn Dataset
- File Format: CSV
- Target Variable: Churn
- Problem Type: Binary Classification
The dataset contains customer details, service subscriptions, contract information, payment methods, and churn status.

The analysis focuses on:

- Customer Churn Distribution

- Correlation Heatmap


# MACHINE LEARING

This project uses a Classification approach to predict customer churn.

The model learns patterns from historical customer data and predicts whether a customer is likely to leave the service.


# EXPECTED OUTCOME
